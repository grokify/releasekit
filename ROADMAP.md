# ReleaseKit Roadmap

This roadmap documents planned and completed features for this project.

The format is based on and generated by [Structured Roadmap](https://github.com/grokify/structured-roadmap), which provides a machine-readable JSON intermediate representation with deterministic Markdown generation.

## Overview

ReleaseKit is a Go toolkit and CLI for accelerating release management of individual repositories. It consolidates git operations, commit analysis, release readiness checks, and workflow orchestration into a single, composable library with LLM-optimized (TOON) output.

## v0.1.0 - Core Git Operations & Release Status 📋

Foundation with git operations library, commit analysis, and CLI status commands

### [ ] Commit log with range queries

Execute git log with since/until refs, last N, path filtering, and numstat

**Target:** 0.1.0

### [ ] Repo type with configurable working directory

Core abstraction for executing git commands in a specific directory

**Target:** 0.1.0

### [ ] Tag listing with prefix filtering and version sorting

List, create, verify, and delete tags with support for nested module prefixes (e.g., sdk/go/v0.1.0)

**Target:** 0.1.0

### [ ] `releasekit status` command

Show latest tag, commits since, uncommitted changes in one invocation. Replaces 5+ manual git commands.

**Target:** 0.1.0

- [ ] Show latest tag and commit it points to
- [ ] List commits since last tag with conventional commit parsing
- [ ] Show uncommitted changes summary
- [ ] Support --path for nested module prefix
- [ ] Show suggested next version based on commit types
- [ ] TOON output by default

### [ ] Category suggestion with confidence scoring

Map conventional commit types to changelog categories with confidence levels

**Target:** 0.1.0

### [ ] Conventional commit parser

Regex-based parsing of type(scope)!: subject with breaking change detection

**Target:** 0.1.0

### [ ] JSON formatter

Structured JSON output for programmatic use

**Target:** 0.1.0

### [ ] Remote URL parsing

Parse SSH and HTTPS remote URLs into owner/repo structure, normalize to HTTPS

**Target:** 0.1.0

### [ ] Suggested next version

Compute next semver based on conventional commits since last tag (feat → minor, fix → patch, BREAKING CHANGE → major)

**Target:** 0.1.0

### [ ] TOON formatter

Token-optimized output format for LLM consumption (~8x more efficient than raw git)

**Target:** 0.1.0

### [ ] Working tree status

Parse staged, unstaged, and untracked file state

**Target:** 0.1.0

### [ ] `releasekit check` command

Validate version consistency between tags and CHANGELOG.json entries

**Target:** 0.1.0

- [ ] Compare tags against CHANGELOG.json versions
- [ ] Detect version mismatches (changelog vs actual tags)
- [ ] Detect tags with no corresponding CHANGELOG entry (backfill detection)
- [ ] Validate semver format

### [ ] `releasekit commits` command

Parse commits in a range with conventional commit analysis and category suggestions

**Target:** 0.1.0

- [ ] Support --since, --until, --last, --path flags
- [ ] Category suggestions per commit
- [ ] Summary statistics by type

### [ ] `releasekit modules` command

Show status of all Go submodules in a repo with per-module tag and delta

**Target:** 0.1.0

- [ ] Detect Go submodules (go.mod files)
- [ ] Show per-module latest tag and commits since
- [ ] Show per-module uncommitted changes

### [ ] Branch ahead/behind tracking

Detect branch tracking state relative to remote

**Target:** 0.1.0

### [ ] Issue/PR reference extraction

Extract #123 and (#456) references from commit messages

**Target:** 0.1.0

### [ ] Text formatter

Human-readable terminal output

**Target:** 0.1.0
